# Habilidades do CX Co-worker

{{preview-fast-release-general}}

>[!IMPORTANT]
>
>Atualmente, o CX Coworker não está disponível para organizações de assistência médica, finanças ou alguns outros setores com dados confidenciais. O Assistente de IA está disponível para essas organizações. Para obter mais informações, consulte [Visão geral do Assistente de IA](/help/quicksilver/workfront-basics/ai-assistant/ai-assistant-overview.md).

Este artigo lista as habilidades que estão disponíveis no momento para o CX Coworker no Workfront.

As habilidades cobertas por essas habilidades estão disponíveis no CX Coworker por meio da interface conversacional, e você não precisa chamá-las diretamente. No entanto, se você quiser chamar as habilidades diretamente, poderá fazê-lo no painel Colaborador inserindo uma barra `/` e digitando o nome da habilidade.

Por exemplo, prompts, consulte os prompts no artigo [Usar o servidor MCP do Adobe Workfront](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md).

## Habilidades do Workfront Planning

### Arquiteto de Soluções do Workfront Planning

Nome: `wf-planning-solution-architect`

Esta habilidade pode responder a perguntas relacionadas ao Workfront Planning, incluindo, mas não limitado a:

* Design do Workspace
* Sintaxe do campo de fórmula
* Filtragem de API
* Gravar conexões
* Opções de automação
* Relatórios
* Acesso e permissões
* Integrações
* Limites de produto por tipo de preço

### Gerenciar o Workfront Planning

Nome: `manage-workfront-planning`

Essa habilidade consulta e gerencia objetos do Workfront Planning como:

* Espaços de trabalho
* Seções
* Tipos de registro
* Campos
* Exibições
* Registros

### Gerenciar objetos do Workfront

Nome: `manage-workfront-objects`

Essa habilidade cria e atualiza projetos, tarefas, problemas, portfólios e programas do Workfront. Os exemplos incluem, mas não estão limitados a:

* Criação de um projeto
* Adicionar uma tarefa
* Definição de datas planejadas
* Atribuir uma tarefa

### Consultar dados do Workfront

Nome: `query-workfront-data`

Essa habilidade encontra, lista e cria relatórios sobre objetos do Workfront como:

* Projetos
* Tarefas
* Problemas
* Usuários
* Portfólios
* e muito mais
