# Aprimoramentos do projeto do quarto trimestre de 2026

Esta página descreve as melhorias feitas no Project com a versão do quarto trimestre de 2026 para o ambiente de Pré-visualização. Essas melhorias serão disponibilizadas no ambiente de produção, conforme indicado.

Para obter uma lista de todas as alterações disponíveis neste momento do ciclo de lançamento do quarto trimestre de 2026, consulte [Visão geral da versão do quarto trimestre de 2026](/help/quicksilver/product-announcements/product-releases/26-q4-release-activity/26-q4-release-overview.md).

## Campos financeiros preservados ao criar um projeto a partir de um modelo

>[!NOTE]
>
>Visualização: 30 de julho de 2026
>Versão rápida de produção: 13 de agosto de 2026
>Produção para todos: 15 de outubro de 2026

Quando um modelo contém dados financeiros, esses valores de campo são preservados quando um usuário cria um projeto a partir do modelo. O usuário deve ter acesso de Visualização de Dados Financeiros para visualizar os campos financeiros nos detalhes do projeto.

Anteriormente, se o usuário não tivesse acesso de edição aos valores, eles eram redefinidos como zero.

Para obter informações, consulte [Criar um projeto usando um modelo](/help/quicksilver/manage-work/projects/create-projects/create-project-from-template.md) e [Gerenciar informações na área Finanças do projeto](/help/quicksilver/manage-work/projects/project-finances/manage-project-finance-area.md).
