# Atividade da quarta versão do trimestre de 2026 para recursos de disponibilidade limitada do Adobe Workfront

Este artigo descreve a disponibilidade limitada dos recursos do Workfront que estão sendo lançados durante o terceiro trimestre de 2026.

Para obter uma lista de todos os recursos de disponibilidade limitada lançados para o Adobe Workfront, consulte [atividade de lançamento dos recursos de disponibilidade limitada do Adobe Workfront: índice do artigo](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md).

## Notas de versão para recursos de disponibilidade limitada

Esta seção inclui as notas de versão da nova funcionalidade.

### Migração de relatórios divididos em fases no tempo para listas aprimoradas

>[!NOTE]
>
>Data de lançamento da produção: a ser definida

Os Relatórios divididos em fase no tempo estão migrando para o formato de lista aprimorado, que fornece um gerenciamento de exibição aprimorado. Em uma lista aprimorada, você pode definir rapidamente as preferências para filtrar e agrupar dados, além de exibir ou ocultar colunas. Essas preferências são combinadas como uma &quot;visualização&quot; que pode ser salva e compartilhada com outros usuários. É possível criar relatórios a partir de modelos gerais e usar visualizações para organizar a estrutura do relatório e restringir o escopo dos dados.

Quaisquer configurações que os usuários já tenham definido nos relatórios existentes antes da migração (filtros, agrupamentos, visibilidade da coluna) são preservadas e convertidas em uma exibição na categoria **Minhas Exibições**. Qualquer pessoa com acesso ao relatório terá essa visualização compartilhada com ela automaticamente.

Uma visualização padrão também é criada para cada tipo de relatório. Em um relatório de tarefa, por exemplo, o padrão é chamado de &quot;Exibição padrão da tarefa dividida em fases&quot;. O administrador do sistema pode definir qual visualização é o padrão para cada tipo de relatório nos modelos de layout.

>[!NOTE]
>
>Os dados existentes no sistema não estão sendo alterados. Somente as visualizações dos dados foram alteradas nos relatórios.

Para obter mais informações sobre exibições e listas aprimoradas, consulte [Usar listas aprimoradas](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md).
