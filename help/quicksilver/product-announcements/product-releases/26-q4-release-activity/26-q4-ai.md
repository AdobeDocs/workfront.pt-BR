# Aprimoramentos da IA do quarto trimestre de 2026

Esta página descreve as melhorias de IA feitas com a versão do quarto trimestre de 2026 para o ambiente de Pré-visualização. Essas melhorias serão disponibilizadas no ambiente de produção, conforme indicado.

Para obter uma lista de todas as alterações disponíveis neste momento do ciclo de lançamento do quarto trimestre de 2026, consulte [Visão geral da versão do quarto trimestre de 2026](/help/quicksilver/product-announcements/product-releases/26-q4-release-activity/26-q4-release-overview.md).

## Novas ferramentas de Aprovação disponíveis no Conector MCP do Workfront

>[!NOTE]
>
>Visualização: 30 de julho de 2026>Versão rápida de produção: 13 de agosto de 2026>Produção para todos: 15 de outubro de 2026

Para expandir os recursos do Conector MCP do Workfront, adicionamos as seguintes novas ferramentas:

* Adicionar caminho à aprovação
* Remover caminho da aprovação
* Adicionar estágio ao caminho
* Remover estágio do caminho
* Reordenar estágios no caminho

Além disso, as seguintes ferramentas foram estendidas para acomodar caminhos de aprovação paralelos:

* Obter informações de fluxo de trabalho de aprovação
* Criar ou atualizar fluxo de trabalho de aprovação
* Criar aprovação a partir do modelo

Para obter mais informações, consulte [ferramentas do servidor MCP do Adobe Workfront](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## Ferramentas de placa disponíveis no conector MCP Workfront

>[!NOTE]
>
>Visualização: 30 de julho de 2026>Versão rápida de produção: 13 de agosto de 2026>Produção para todos: 15 de outubro de 2026

Para expandir os recursos do Conector MCP do Workfront, adicionamos as seguintes ferramentas para trabalhar com placas:

* Obter painel
* Obter cartão
* Criar quadro
* Criar cartão
* Atualizar cartão
* Conectar cartão
* Criar tag do painel
* Criar, atualizar ou excluir itens da lista de verificação
* Criar, atualizar ou excluir colunas do quadro

Para obter mais informações, consulte [ferramentas do servidor MCP do Adobe Workfront](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).
