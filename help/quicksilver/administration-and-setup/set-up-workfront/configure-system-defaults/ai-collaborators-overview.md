# Colaboradores de IA

Os Colaboradores de IA são agentes de IA que podem ser atribuídos a tarefas da mesma forma que uma pessoa é atribuída. Você pode ajustar os Colaboradores de IA em seus fluxos de trabalho existentes, liberando sua equipe para se concentrar no que é mais importante.

## Colaboradores de IA no trabalho

Veja como um Colaborador de IA pega e conclui tarefas no Workfront.

Para obter mais informações sobre os Colaboradores de IA, consulte [Configurar Colaboradores de IA](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/configure-ai-collaborators.md).
